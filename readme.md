# Zero-Day Network Intrusion Detection System

## Project Overview
A machine-learning-based network intrusion detection system designed to investigate the detection of previously unseen attack families using few-shot learning.

## Proposed Approach
- 1D-CNN feature encoder
- Prototypical Networks
- Few-shot learning for unseen attack-family detection
- Random Forest baseline for comparison
- Optional GA/PSO-based feature selection
